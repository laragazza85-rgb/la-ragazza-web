Flujo seguro Admin → API → Supabase/RLS

Diagrama de secuencia funcional para explicar como una accion del panel admin se autentica, se valida, se consulta con Query Builder y se restringe con RLS.

Navegador/Admin

Supabase Auth

API Parcial Express

Supabase/Postgres

1. Carga admin

El browser recibe HTML/JS desde Vercel y crea el cliente Supabase publico.

2. Login/signup

Supabase Auth recibe email/password, valida credenciales y administra hashes internos.

3. Sesion + JWT

Devuelve access token. La app no almacena passwords en tablas propias.

4. Sesion local

El navegador guarda la sesion Supabase y la refresca automaticamente.

5. Accion admin

Reserva, consulta o solicitud. El fetch incluye Authorization: Bearer JWT.

6. requireAuth

Extrae Bearer token, llama getUser(token) y carga profile con role.

7. Validacion

Servicios validan dominio, longitudes, fechas, roles y rechazo de markup HTML.

8. Repositorio

Usa Supabase Query Builder: insert, update, select, eq, in. No SQL crudo.

10. Respuesta segura

Devuelve JSON. El admin escapa datos con escapeHtml antes de renderizar.

Auth metadata

Supabase valida JWT y mantiene hash/encrypted password en esquema auth.

9. RLS

Postgres filtra filas segun auth.uid() y politicas de rol.

Datos

profiles, bookings y role_change_requests. Sin columna password propia.

11. Render UI

textContent para mensajes, .value para formularios y escapeHtml para plantillas.

Credenciales solo hacia Supabase Auth JWT emitido por Supabase Bearer token en API calls Validacion de identidad Consulta parametrizada RLS decide filas visibles/modificables 401/403/400 si falla auth, rol o validacion

Password handling

La app nunca compara ni guarda passwords. Supabase Auth controla credenciales y emite tokens.

Prepared statements

En este stack, el Query Builder separa estructura y valores, evitando SQL interpolado.

XSS

Campos libres rechazan markup en backend y se escapan antes de renderizar en admin.

RLS

Postgres aplica politicas por fila bajo el contexto del JWT del usuario.
