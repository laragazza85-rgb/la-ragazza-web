Arquitectura Cloud Desplegada

Separacion entre frontend estatico en Vercel, API Node/Express en Render y proveedor administrado Supabase para Auth y Postgres.

Cliente

Vercel CDN / Static Hosting

Render / Node Runtime

Supabase Cloud

Navegador

Usuario/admin. Mantiene sesion Supabase y envia JWT como Bearer token.

Sitio Astro

Paginas estaticas, assets y panel admin servido desde Vercel.

Admin JS

Login con Supabase Auth, escape HTML y llamadas API con Authorization.

API Parcial

Express: Helmet, CORS, requireAuth, validacion y reglas de negocio.

Controles

Query Builder, RLS, JWT, XSS validation, service key solo server-side.

Supabase Auth

Gestiona credenciales, hashes internos, sesiones y emision de JWT.

Postgres + RLS

Tablas profiles, bookings y role_change_requests con politicas por fila.

GET HTML, JS y CSS desde Vercel signIn/signUp y sesion en navegador fetch /api con Bearer JWT validacion de token consultas parametrizadas via Query Builder
ConfidencialidadJWT y service role key no se exponen en repositorio; password vive en Supabase Auth.
IntegridadServicios validan dominio; repositorios no concatenan SQL.
DisponibilidadFrontend estatico y API separada reducen acoplamiento operacional.
AuditoriaRepositorios, servicios y tests muestran evidencia de controles.
