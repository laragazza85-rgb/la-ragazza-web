Matriz CIA, controles y riesgos residuales

Vista de auditoria para explicar que activos se protegen, que propiedad de seguridad domina en cada caso y que controles concretos existen en el codigo o la arquitectura.

Confidencialidad

Protege secretos, sesiones, datos personales y credenciales. Se apoya en Supabase Auth, JWT, RLS y en no exponer la service role key al frontend.

Integridad

Protege que los datos no sean alterados por usuarios no autorizados. Se apoya en validacion de servicios, Query Builder, RLS y controles de rol.

Disponibilidad

Protege que el sitio y el panel sigan operando. Se apoya en frontend estatico, API separada, proveedores administrados y pruebas automatizadas.

Controles verificables

Passwords Supabase Auth gestiona hashes. La app solo guarda profiles sin columna password.
Prepared statements equivalentes Repositorios usan Supabase Query Builder: insert, update, select, eq, in.
RLS Postgres filtra acceso a filas bajo el contexto del JWT.
XSS Backend rechaza markup HTML persistente; frontend usa escapeHtml/textContent.
CORS Preflight OPTIONS no requiere auth y solo permite origenes configurados.
Secretos Service role key solo debe vivir en API host, nunca en cliente.
